# RAS v. 2.0 — плагин компании для Revit

Один плагин для Revit 2023 и 2026, внутри — модули (функции). На ленте — вкладка «RAS v. 2.0», у каждого модуля своя панель.

## Модули

| Модуль | Что делает | Revit |
|---|---|---|
| RAS-Model History | Журнал изменений модели: кто, что и когда создал, изменил или удалил ([описание](src/Modules/RAS-Model%20History/README.md)) | 2026 |

## Обновление

Ставить новые версии не нужно: при запуске Revit плагин сам берёт актуальную версию с сервера компании.
Если разработчик попросил «перезапустить Revit» — закройте Revit и откройте снова.
Нет связи с сервером — работает последняя загруженная версия.

Тестовая группа (кто получает новые версии первым) — в `Config\test-users.txt` на сервере.

## Для разработчиков

- [PRINCIPLES.md](PRINCIPLES.md) — принципы устройства и разработки: ядро и модули, выпуск версий, правила кода. Прочитать первым.
- [CLAUDE.md](CLAUDE.md) — как собрать, проверить и выпустить; текущие планы.
- `MODULE.md` в папке каждого модуля — устройство модуля и его правила (например, [RAS-Model History](src/Modules/RAS-Model%20History/MODULE.md)).

## О плагине

Кнопка «О плагине» на вкладке «RAS v. 2.0»: версия (сборка), модули и их состояние, журнал ошибок.
Если что-то не работает, откройте журнал ошибок из этого окна и перешлите файл разработчику.
