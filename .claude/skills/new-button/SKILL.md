# Новая кнопка модуля

Образец — кнопка «ID элемента связи» (29.10.2026): `src\Modules\RAS-Clash Analysis\Revit\BridgeApp.cs` (`AddButton`, `ShowElementIds`), `Commands.cs` (`ElementIdCommand`, `AlwaysAvailable`), `UI\ElementIdWindow.xaml(.cs)`, `Icons\LinkedId.svg`. Самый маленький модуль целиком — `src\Modules\RAS-Sheet Manager`.

Перед началом — `MODULE.md` и `DECISIONS.md` модуля. Раскладку окна — по рисунку разработчика или после наброска (навык `ui-sketch`).

## 1. Код кнопки и команда

- Код кнопки — `<Id модуля>.<Имя>`, например `ClashAnalysis.LinkedId`. **После выпуска не меняется**: от него зависят раскладка, доступ, горячие клавиши людей.
- Команда — тонкая, вся работа в классе модуля:
  ```csharp
  [Transaction(TransactionMode.ReadOnly)]   // меняет модель — Manual и транзакция с именем по правилам ядра
  public sealed class ElementIdCommand : IExternalCommand
  {
      public Result Execute(ExternalCommandData commandData, ref string message, ElementSet elements)
      {
          BridgeApp.Instance?.ShowElementIds(commandData.Application);
          return Result.Succeeded;
      }
  }
  ```
- Метод модуля — целиком в `try/catch`: `_log.Error("<Кнопка>: что не вышло", ex)` и `TaskDialog` по-русски — что случилось и что делать («подробности в журнале плагина («О плагине» → «Показать журнал ошибок»)»). Исключение не должно уйти в Revit.
- Нечего делать (ничего не выделено, не тот вид, не то семейство) — `TaskDialog` с подсказкой, что сделать, а не тишина.

## 2. Объявить кнопку

В `Start` модуля:
```csharp
var ids = context.AddButton("LinkedId", "ID элемента\nсвязи", typeof(ElementIdCommand),
    "Подсказка — одна строка: что делает", icon: "LinkedId");
ids.LongDescription = "Подробнее: как пользоваться, что получится.";
```
- Подпись — коротко, по-русски, `\n` — перенос; «ёлочки», без англицизмов.
- Должна нажиматься без открытой модели (настройки и т. п.) — `ids.AvailabilityClassName = typeof(AlwaysAvailable).FullName;`. Класс `AlwaysAvailable` — **свой в сборке модуля**: Revit ищет его в сборке команды, класс ядра не сработает.
- Модулю нужно знать, доступна ли кнопка человеку (например, прятать часть окна) — `context.IsAllowed("<Имя>")`.

## 3. Место на ленте — `src\Core\ribbon.txt`

- Строка кода кнопки под нужной панелью `[Панель]` (и отделом `[[Отдел]]`), своя подпись — `подпись="…"`, доступ — `доступна="BIM"` (группы из `{Люди}` или логины). Стопка маленьких кнопок — `( … )`, 2–3 штуки. Синтаксис — в начале файла.
- Без строки кнопка встанет на панель с названием модуля — обычно это не то, что нужно.
- Перенос уже выпущенной кнопки на другую панель сбрасывает людям горячие клавиши и панель быстрого доступа — только обдуманно, сказать разработчику.
- В файле бывают незакоммиченные правки разработчика (люди в `{Люди}`) — их не трогать и не коммитить вместе со своими без спроса.

## 4. Иконка

- `Icons\<Имя>.svg` в папке модуля, по `tools\IconBuilder\СТИЛЬ.md`: `viewBox 0 0 32 32`, контур `#39424E` толщиной 2, заливка `#FFFFFF`, одна деталь акцентом `#2F6FED` (заменяется цветом отдела из `Icons\department.txt`), линии по нечётным координатам, без текста и градиентов. На 16×16 каша — рядом `<Имя>.16.svg`.
- `icons.cmd` — делает `<Имя>32.png`, `<Имя>16.png` и тёмные `.dark`, лист просмотра `out\icons-preview.png` — посмотреть его (Read).
- В `.csproj` модуля уже есть `<EmbeddedResource Include="Icons\*.png" LogicalName="Icons.%(Filename)%(Extension)" />`; новый модуль — добавить так же (и `<None Remove="Icons\*.png" />`).
- Коммитятся и SVG, и PNG.

## 5. Окно WPF (если у кнопки окно)

- Конструктор: `RASv2.Core.WindowTheme.Apply(this);` **до** `InitializeComponent()`. Цвета — только `{DynamicResource Bg | Fg | Muted | Field | Line | Row | Hover | Pressed | Accent | AccentFg | Error}`; кнопки — образцы ядра (обычная, `PrimaryButton`, `IconButton`, `LinkButton`).
- **Ключи своих стилей не должны совпадать с именами кистей** (`Row`, `Line`, `Field`…): 29.10.2026 стиль `Row` уронил окно «Категории элементов» на загрузке XAML. Называть по смыслу: `CatRow`, `Hint`, `IdBox`.
- Хозяин окна — Revit: `new WindowInteropHelper(window).Owner = app.MainWindowHandle;`.
- Окно из окна (`ShowDialog` внутри обработчика кнопки окна) — в `try/catch` внутри обработчика: исключение, ушедшее сквозь вложенный `ShowDialog`, ломает окна и роняет Revit.
- Текст — по-русски, коротко, даты «ДД.ММ.ГГГГ ЧЧ:ММ», сообщение отвечает «что случилось и что делать».
- **Проверка вне Revit** — после каждой правки XAML: собрать модуль под 2023, затем свой скрипт в scratchpad (UTF-8 с BOM) на `window_shot.ps1` из папки этого навыка и `powershell -NoProfile -STA -ExecutionPolicy Bypass -File <скрипт>`; посмотреть PNG. Пример и ловушки PowerShell (список — `@(,$list)`, `$null` → `""`) — в начале `window_shot.ps1`. Тёмную тему так не увидеть (`RevitCompat.IsDarkTheme` вне Revit — светлая): смотреть, что нет жёстких цветов.

## 6. Различия Revit 2023 и 2026

- Revit API, которого нет в одной из версий, — через `RevitCompat` ядра (`src\Core\RevitCompat.cs`); нет там — добавить в ядро, а не `#if` в модуле. `#if REVIT2023` в модуле — только в исключительном случае и с комментарием.
- `ElementId` — 2023: `IntegerValue`, 2026: `Value` (long) — через `RevitCompat.Value(id)` и `RevitCompat.Id(число)`.
- Возможности языка и библиотек — те, что есть и в .NET Framework 4.8.
