# [[Отдел]]                       — отдел; панели под ним видны, когда он выбран («О плагине» → отдел).
#                                   Панели до первого отдела видны во всех отделах. Нет ни одного отдела — переключателя нет.

# [Панель]                        — панель; под ней — кнопки по порядку слева направо.
# Код.Кнопки                      — большая кнопка с подписью модуля (коды и подписи — в окне «О плагине»).
# Код.Кнопки подпись="Текст"      — своя подпись; подпись="" — без подписи; \n — перенос строки; \" — кавычка.
# (                               — стопка: 2–3 маленькие кнопки в одну колонку, у каждой можно своя подпись.
# Код.Один
# Код.Два
# )                               — несколько стопок подряд — несколько пар скобок.
#
# Кнопка, которой здесь нет, — на панели с названием своего модуля, во всех отделах.
# Кнопки модуля, который не запустился или не работает в этой версии Revit, не появляются; пустые панели не создаются.
# Ошибка в строке ленту не ломает: причина — в журнале ошибок (ras.log).
