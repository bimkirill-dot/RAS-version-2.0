# «Модули и кнопки — одним файлом»). Файл едет в сборке: поменять — правка, revit.cmd: пункт 1 (себе) / выпуск,
# перезапуск Revit. Меняет только тот, кто выпускает плагин.
#
# ───── {Модули} — какие модули работают ─────
# <код модуля> = работает | только тест | выключен | не загружать
#   работает      — как обычно (так же — если модуля здесь нет)
#   только тест   — модуль работает только у тестовой группы (Config\test-users.txt на сервере); у остальных его кнопок нет
#   выключен      — модуль не запускается, его кнопок нет
#   не загружать  — сборка модуля не загружается совсем — если он ломает запуск плагина
#
# ───── {Люди} — группы людей для кнопок ─────
# <группа> = логин, логин        — логины Windows, как %USERNAME% (например, Poletayev_BIM); «всем» и «никому» — не имена групп
#
# ───── Лента ─────
# [[Отдел]]                       — отдел; панели под ним видны, когда он выбран («О плагине» → отдел).
#                                   Панели до первого отдела видны во всех отделах. Нет ни одного отдела — переключателя нет.
#                                   На переключателе — название отдела. «О плагине» ставить на панель до первого отдела.
# [Панель]                        — панель; под ней — кнопки по порядку слева направо.
# Код.Кнопки                      — большая кнопка с подписью модуля (коды и подписи — в окне «О плагине»).
# Код.Кнопки подпись="Текст"      — своя подпись; подпись="" — без подписи; \n — перенос строки; \" — кавычка.
# Код.Кнопки доступна="…"         — кому кнопка нажимается: группы из {Люди} и логины через запятую; «никому» — серая у всех.
#                                   Не указано — всем. Кнопка видна всегда: у кого недоступна — серая, в подсказке — почему.
# (                               — стопка: 2–3 маленькие кнопки в одну колонку, у каждой можно своя подпись.
# Код.Один
# Код.Два
# )                               — несколько стопок подряд — несколько пар скобок.
#
# Кнопка, которой здесь нет, — на панели с названием своего модуля, во всех отделах, доступна всем.
# Ошибка в строке ничего не ломает и не прячет: строка пропускается, причина — в журнале ошибок (ras.log).
# Перенос кнопки на другую панель сбрасывает у пользователей её горячие клавиши и место на панели быстрого доступа
# (Revit помнит кнопку по вкладке и панели).
