# RAS-Block Mirror Rotation

Отражение (потом — поворот) блока КЖ без поломки оформления на видах. Для отдела КЖ; пока проверяем — только ведущий
разработчик (`ribbon.txt`: `BlockMirrorRotation = только тест`, кнопка `доступна="Poletayev_BIM"`).

## Зачем

Блок КЖ — отдельный файл, отсоединённая копия соседнего блока. Его отражают командой Revit «Отразить проект» (потом —
поворачивают «Повернуть север проекта»), и на видах ломается оформление: текст марок арматуры повёрнут, высотные отметки
не работают, оси короче, кружки осей на другом конце, имена осей надо перебивать, в размерах нули, пропадают сегменты и
целые размеры. Руками это чинят на 100–300 листах.

## Как устроен

- Модуль — `RASv2.BlockMirrorRotation.csproj` (`IModule.Id` — `BlockMirrorRotation`), Revit 2023 и 2026. Кнопка
  «Отразить блок» (`BlockMirrorRotation.Mirror`, значок — два зеркальных блока и ось, `Icons\Mirror.svg`, отдел КЖ), отдел
  «КЖ», панель «Блоки».
- `MirrorApp.cs` — кнопка: проверки → окно `UI\MirrorWindow.xaml` → запомнить оформление (`Revit\Snapshot.cs`) → команда
  Revit «Отразить проект» (`PostCommand`, ось человек выбирает в её окне) → после неё, в простое Revit, — отражение
  находится по положению элементов модели (`Logic\PlanTransform.cs`) → восстановление (`Revit\Restorer.cs`, одна операция —
  одно Ctrl+Z) → окно итога `UI\ResultWindow.xaml` (щелчок по строке — вид и элемент) и журнал.
- `Logic\` — без Revit API, с тестами (`tests\RASv2.Tests\BlockMirrorTests.cs`): отражение по парам точек, имена осей
  (`GridNaming.cs`), сторона кружков (`BubbleSides.cs`), нулевые сегменты размеров (`ZeroSegments.cs`).
- Журнал каждого запуска — `%LocalAppData%\RAS_v_2.0\RAS-Block Mirror Rotation\Журналы\`.

Описание до реализации и решения — `DECISIONS.md`.
