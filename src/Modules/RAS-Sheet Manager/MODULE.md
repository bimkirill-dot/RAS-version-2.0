# RAS-Sheet Manager

Инструменты для листов — панель «Менеджер листов» (отдел BIM). Сейчас одна кнопка — **«Подпись»**: очистка DWG-подписей и добавление их в семейство подписей. Что добавлять дальше — решает разработчик (DECISIONS.md).

Revit 2023 и 2026. Код модуля — `SheetManager`, сборка `RASv2.SheetManager.dll`, кнопка `SheetManager.Sign` (в `ribbon.txt` — `доступна="BIM"`).

## «Подпись» — как пользоваться

1. Открыть семейство подписей (например, `RAS_Фамилия`, `RAS_Фамилия_ГИП`) и его вид с подписями (обычно «Лист»).
2. «Подпись» → предупреждение «Убедитесь, что вы находитесь в нужном семействе подписей» с именем семейства → «ОК».
3. В окне — папка с исходными подписями (по умолчанию — из настроек, потом — последняя). Новые подписи очищаются сами (AutoCAD Core Console, в фоне), рядом — в подпапке `clean` — появляются `…_clean.dwg`; очищенные не трогаются.
4. Поиск над списком — по фамилии или имени файла (находит и уже добавленные). Список: картинка подписи, фамилия (из имени файла, можно поправить), номер, что будет, размер, вес DWG (исходный → очищенный). Уже добавленные скрыты — «Показать уже добавленные», чтобы заменить DWG.
   Имя файла не по регламенту («[Отдел]_Подпись_Фамилия.dwg»; «#» — главный специалист; «!» и ГИП или ГАП на месте отдела) — предупреждение окном и полосой над списком со ссылкой «Регламент наименования подписей»; такая подпись не чистится и не добавляется.
   Настройки очистки поменялись — у подписи «очищена по прежним настройкам»; «Обновить ▾» → «Все подписи в папке» или «Отмеченные» — очистить заново (очищенные файлы заменяются); уже стоящие в семействе отмечаются, чтобы «Добавить» заменило их DWG.
   «Актуализировать…» — проверка семейства (`Logic\SignAudit`, тесты) → окно со списком находок (что плагин исправит сам — с галочкой, остальное — сведения) → «Исправить отмеченные» одной группой (одно Ctrl+Z). Находки: подписи без файла в папке и вставленные вручную (убрать целиком: DWG с типом, параметр, строку таблицы), строки таблицы без подписи и дубли, один номер у двух фамилий (только сведения), номер в формуле не как в таблице, две вставки у человека, вставки ни к кому не привязанные, типы DWG без вставок, пустой или чужой текст для штампа у ГИП (вписать инициал тут же), очищенные файлы без исходного (удалить из «clean»). Параметр без подписи и подпись старее очищенного файла — отмечаются в списке окна «Подпись», их добавит «Добавить». Сдвинутые с общей точки подписи не трогаются.
5. Таблица выбора — из таблиц семейства (какая будет формула — в подсказке: как в формулах семейства, а нет их — из настроек, раздел «Формула»); остальные столбцы таблицы — в списке у новых строк (если в семействе их несколько — та, на которую ссылается больше формул), масштаб (у ГИПов подпись крупнее; запоминается для семейства), «Добавить».
6. Отчёт: сколько добавлено, кодировка таблицы и самопроверка, точка, масштаб; по каждой подписи — «Подробнее».

## Как устроено

**Семейство подписей** (уже существует, кнопка его дополняет): текстовый параметр экземпляра `Фамилия`; таблица выбора `RAS_Таблица выбора фамилий` (`,Фамилия##other##,Да/Нет##number##general`, строки «Иванов,Иванов,12», пустая «,,0»); на каждого человека — параметр Да/Нет с его фамилией (группа «Видимость»), формула `size_lookup("<таблица>", "Да/Нет", 1000, Фамилия) = 12`; DWG подписи, видимость которого привязана к этому параметру. Номер человека постоянный, не переиспользуется. Имена таблиц, параметра, столбца, значения по умолчанию — в настройках (в коде их нет — PRINCIPLES.md, ред. 10); у существующего семейства форма формулы берётся из самого семейства.

**Очистка** (`Logic\`, без Revit API, с тестами `SheetSignTests`) — перенос `dwg_clean.py`:
- `AcadConsole` — AutoCAD Core Console без окна: DWG → DXF (`DXFOUT`), чистый DXF → DWG 2018 (`CONVERTPOLY` — лёгкие полилинии, `INSUNITS` 4, `PURGE`). Сценарий `.scr` — латиницей; пути в нём — **только латиницей и без пробелов**: пробел в сценарии — это Enter (27.10.2026 путь `…\RAS-Sheet Manager\work` рвался, и AutoCAD ждал ввода вечно). Рабочая папка — `SignFolder.WorkRoot`: `Temp\RASv2_sign`, запасная — `ProgramData\RAS_v_2.0\work`. AutoCAD, не ответивший за минуту, снимается; закрыли окно — сразу. Самый новый AutoCAD находится сам, путь можно задать в настройках.
- `DxfDocument` — разбор текстового DXF: единицы, выключенные и замороженные слои, блоки, объекты модели (лист — код 67 = 1 — не берётся).
- `SignGeometry` — объекты в ломаные: отрезки, полилинии (с выпуклостью, сглаженные — только вершины кривой), дуги, окружности, эллипсы, сплайны (де Бур), блоки (масштаб, поворот, зеркало — нормаль объекта, массивы, вложенные до 10), штриховки — контуром; тексты, размеры, точки, выноски, невидимые (код 60 = 1) — выбрасываются.
- `SignCleaner` — сшивка кусков, стыкующихся концами, прореживание (Дуглас — Пекер, 0,02 мм), один размер (по умолчанию высота 7 мм, ширина не больше 22 мм), центр — в 0,0; `DxfWriter` — DXF R12: только полилинии на слое 0, синий (цвет 5), мм.
- `SignFolder` — папка: исходные (`*.dwg`, `*.dxf` без `_clean`), очищенные — `clean\<имя>_clean.dwg`; новые чистятся по 3–6 сразу; картинки очищенных — в кэше на компьютере (`Картинки подписей`, ключ — путь, размер и время файла), чтобы не запускать AutoCAD при каждом открытии окна.

**Добавление** — перенос «Добавить подписи» (pyRevit, `Desktop\Подписи`) с исправлениями (DECISIONS.md):
- `SignNames`, `SignFormula`, `SizeTable`, `TableEncodings`, `SignPlan` — без Revit API, с тестами: фамилия из имени файла; что допустимо; формула; CSV таблицы (кавычки, столбцы по заголовку); кодировки (UTF-8 с BOM, UTF-8, Windows-1251 — в .NET 8 через поставщика кодовых страниц); план — «новая», «параметр есть, подписи нет», «уже добавлена — заменить», «формула другая / на другую таблицу», «пропуск» с причиной; номера — только отмеченным, подряд.
- `Signing\SignFamily` (Revit API): таблицы выбора и какая у них форма формул; состояние семейства с выбранной таблицей (выгрузка таблицы — резервная копия в `Таблицы выбора` на компьютере); общая точка подписей (самая частая, 0,01 мм). `Apply` — группа «RAS: подписи» (одно Ctrl+Z): таблица (не загрузилась в одной кодировке — следующая), человек целиком — параметр, формула, DWG (вставка по началу координат, мм, только этот вид; открепить → сдвинуть в точку → привязать видимость → закрепить; сбой — откат только его), самопроверка (вписать фамилию — её параметр должен стать «Да»; нет — другая кодировка; ни одна — отмена всего), цвет подписей (стили объектов: категория импорта и её слои), по галочке — таблицы, на которые не ссылается ни одна формула. Масштаб ≠ 1 — способ, который понимает этот Revit, подбирается пробной вставкой (откат) и проверяется по ширине.
- `UI\SignWindow` — окно (кисти ядра `WindowTheme`; ключи своих стилей не совпадают с ключами кистей — `Muted` стиля и кисти перепутывались); `UI\SignSettingsWindow` — шестерёнка, разделы слева: «Папка и размер» («Вернуть по умолчанию»), «Очистка», «Регламент наименования», «Семейство подписей».

**Регламент имени** (`Logic\SignFileName`, тесты): форма «[#|!][Отдел]_<слово>_Фамилия.dwg» (слово — «Подпись», без учёта регистра); отдел — заглавными (список — в настройках, пусто — любые); «!» — обязательно и только у «руководителей» из настроек (ГИП, ГАП), они — на месте отдела; фамилия — с заглавной, буквы одного алфавита, пробел, дефис, точка. Все 119 подписей 27.10.2026 — по регламенту. Регламент — в окне настроек (шестерёнка), текст — `Logic\SignRegulation` из тех же полей, что и проверка (меняются поля — меняется текст); ссылка «Регламент наименования подписей» в окне «Подпись» открывает настройки на нём.

**«Обновить»**: картинка в кэше хранит, чем очищена подпись (`CleanOptions.Key`); не совпадает с нынешними настройками — `SignFile.Outdated`. Перечистка — `SignFolder.Process(…, reclean)`.

**Форма формулы и столбцы таблицы:** `SignForm` (столбец, по умолчанию, ключ), `SignFamily.FormFor` — из формул семейства на выбранную таблицу, нет их — из настроек (`FormColumn`, `FormKey`, `FormDefault`); `SizeTable.NumberColumns` / `ExtraColumns` / `AddRow(…, extra)` / `RemoveRows`. **Актуализация:** `SignFamily.Audit` (люди: параметр Да/Нет с формулой на таблицу и номером > 0 или с привязанным DWG → `SignAudit.Check`) и `Fix` (одной группой); окно — `UI\SignAuditWindow`. **Имя вставленного DWG — по типу вставки** (`CADLinkType.Name`, `SignFamily.DwgName`): в семействе `Category.Name` у всех вставок — «Импорт в семействах». **Отметка на вставке** — Extensible Storage (схема `RASv2SignMark`, когда вставлена, UTC): по ней «очищенный файл новее подписи»; у вставленных раньше её нет — для них эта проверка молчит. **Текст для штампа ГИП** — столбец таблицы, где у большинства строк текст начинается с фамилии и пробела (`SignAudit.DisplayColumn`; в `RAS_Таблица выбора фамилий_гип` — «Инициалы»: «Байгараева Д.»): у новой строки в списке вписывают только инициал, текст складывается сам. **Окна** — общие образцы ядра `WindowStyles` (подключаются `WindowTheme.Apply` до `InitializeComponent`, иначе `StaticResource` на них не найдутся).

**Настройки** (`Logic\SignSettings`): общие — `Data\RAS-Sheet Manager\settings.json` на сервере (сервер не ответил за 5 с — копия на компьютере, сохранить нельзя), личные (`SignPersonal`) — последняя папка и масштаб для каждого семейства.

## Проверено

- Очистка — на 119 подписях (`Desktop\Подписи\DWG`, копия): все очищены за 50–57 с; размеры, число ломаных и точек совпадают с `dwg_clean.py` у 118; у одного файла (в нём чертёж, а не подпись) — по-разному у обоих. Очищенные DWG: только лёгкие полилинии на слое 0, синие, мм, центр в 0,0, ~19 КБ — как у Python.

## Ещё не проверено в Revit

- Всё окно и добавление в Revit 2023 и 2026: семейства `RAS_Фамилия` (около 119 подписей, Windows-1251), `RAS_Фамилия_ГИП`, пустое (`Desktop\Подписи\2023\RAS_Фамилия_пустая_2023.rfa`); казахские фамилии; масштаб ≠ 1; замена DWG; «указать точку»; удаление неиспользуемых таблиц.
- Штриховки: в подписях встретилась одна (в файле-чертеже) — контуром, заливкой не оставляется.
